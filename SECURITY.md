# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub security advisories:
<https://github.com/SpiliosDimakopoulos/twinlens/security/advisories/new>

Do not open a public issue for a vulnerability. Include what you found, how to reproduce it and
the version or commit. You can expect a first reply within a week.

## Supported versions

Only the latest release receives security fixes.
